Metering ROI focused audit (2026-10-06)
Legacy24 packet mapped: enable/type plus four BE16 per-mille coordinates0..1000.
Geometry writes Y/X bounds and scales histogram thresholds by inclusive area.
Gain/fixed-mode gating can reject changes while handler still returns success.
Its apparent getter mutates cached coordinates and returns constant ACK; no
trustworthy current-region backup. Offline full enable/disable replay restores
492 output keys with a declared zero-filled bank8. Stored ISP has seven banks;
live bank8 contents, statistics-plane size and user overlay remain unverified.
No live ROI command sent or supported menu control added. Evidence retained in
metering-roi-replay.json and metering-roi-restore-replay.json.
